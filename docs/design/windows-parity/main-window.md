# Windows 主窗口对齐 Mac（审计 + 实施记录）

范围：主窗口的外壳——工具栏、侧栏、列表栏（标题、排序、筛选、搜索、行、分组）、详情栏的外壳（一条 / 多条 / 没选 / 任务）、
选择、右键菜单、状态菜单、键盘、拖放、空状态、项目菜单、新建事项、命令面板、快捷键面板，以及 Mac 菜单栏命令在 Windows 上的去处。
不含：Agent 会话的终端窗格（SessionsView）、设置页、听写页内部、审核组件本身（web/packages/review）。

规格是 Mac 源码：`MainWindow/MainWindowController.swift`、`MainModel.swift`、`SidebarController.swift`、
`ItemListController.swift`、`ItemCells.swift`、`StateMenu.swift`、`NewItemSheet.swift`、`ProjectPicking.swift`、
`CommandPalette.swift`、`MainMenu.swift`、`JobViews.swift`、`WebHost/*`，文案取 `Resources/{en,zh-Hans}.lproj/Main.strings`。

只在两种情况下和 Mac 不一样：Windows 自己的惯例（Ctrl 不是 ⌘、没有全局菜单栏、F2 重命名、「在文件资源管理器中显示」），
或者系统能力不同（没有 Quick Look、WebView 拖不出文件）。每一处都写了原因。

「Windows 之前」= 2026-11-02 创始人截图里的样子（工具栏 录屏 / 截图 / 语音 / 自动；侧栏 待处理、Agent 会话、全部事项、听写、
项目、未归类、打开文件夹…、设置；全部事项页的 需要你看的 / 未结束 / 已结束 / 全部 / 已丢弃 标签和种类图标）。
