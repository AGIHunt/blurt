# blurt design system (v0.8)

> **中文摘要**
> 这是口喷鸡的设计系统，macOS 应用现在以它为准，之后重做官网也用它。
> - **品牌色是薄荷 `#61DBBD`**，含义只有一个：口喷鸡正在听、正在截、正在替你动手。此外它还用于每屏唯一的主操作，以及列表选中行的底色。

> - **红 = 正在录**，琥珀 = 要你处理，叶绿 + ✓ = 完成，红 = 出错。珊瑚只剩画笔和 issue 类型色。task 类型改为紫色。
> - 系统控件（开关、焦点环、文字选区）跟随系统强调色。

> - 实施：`assets/color/tokens.json` 作为唯一来源，生成 Swift `BrandColor` / `BrandGradient` 和 CSS 变量。附录 A 列出了所有要替换的硬编码颜色。官网这次不改。

## 1. Principles

1. **Mint marks blurt in the act**: listening, capturing, or about to act for you. It also marks the one primary
   action on a screen and the selection in lists blurt draws. If a new use can't be described by that sentence, it
   doesn't get mint.
2. **The gradient is mint's premium form**, for *few, large or hero* things. It is never a background for reading,
   and never a thin line, except the one capture selection.
3. **Most of the app is grey.** Neutral surfaces and text. Colour is information.
4. **Native stays native.** Switches, checkboxes, popups, focus rings and text selection follow the user's system
   accent.
5. **Every coloured state has a shape twin**: dashed vs solid, dot vs ring, check vs "!". It must survive grayscale,
   colour blindness and Reduce Motion.
6. **One direction.** Green is up / start, azure is down / end. No reversed gradients, no extra hues.

## 2. Colour tokens

Contrast is WCAG 2.x relative luminance. Floors: **4.5 : 1** for text, **3 : 1** for icons and UI strokes. "Light
surfaces" are `#FFFFFF / #F6F6F6 / #ECECEC`; "dark surfaces" are `#1E1E1E / #2A2A2A / #323232`. The island and the
capture chrome are always dark, so tokens have an `island` value. Hues are OKLab.

### 2.2 Brand: the gradient

Three stops, sampled from the reference (fresh green top, airy azure bottom, mint where they meet):

| Stop | Hex | OKLab L / C / h | `brand.on` on it | white on it |
|---|---|---|---|---|
| green | `#66D97A` | 0.80 / 0.17 / 147° | 9.05 | 1.78 |
| mint (= `brand.fill`) | `#61DBBD` | 0.81 / 0.12 / 175° | 9.51 | 1.70 |
| azure | `#4AABE2` | 0.71 / 0.12 / 237° | 6.31 | 2.56 |

**Mint is the seam.** A straight OKLab mix of green and azure passes 178°, L 0.75 at the middle. `#61DBBD` sits on
that hue path, 0.06 lighter, and that is the glow where the colours meet. So the flat brand mint needs no re-tune: it
is the gradient's brightest point. Flat mint and gradient read as one family.

Contrast on the gradient: `brand.on` holds ≥ 6.31 : 1 along `linear` and ≥ 4.65 along `deep`. White text fails
everywhere along the gradient (1.70–2.56), so text on the gradient is always `brand.on`. As an edge against a light
surface, the gradient is a fill (like `brand.fill`), never a line. The capture stroke gets its own dark under-stroke.

## 4. Motion with colour

Existing motion vocabulary in the app: a spring with response 0.42 s and damping 0.82 (`Capture/Island/Motion.swift`,
used by the island and the hanging cards); short state fades of 0.14–0.2 s; flashes of 0.32–0.45 s; the spinner turns
every 1.1 s. On web the easing is `cubic-bezier(0.16, 1, 0.3, 1)` and hovers last 120 ms. Every motion respects
Reduce Motion: the still frame must still say the state.

| Moment | Colour | Motion (Reduce Motion → still frame) |
|---|---|---|
| Listening (dictation, voice note, mic test) | G bars + glow | Bars follow the level and settle to 2.5 pt dots in silence. The glow fades in over 200 ms and breathes ±10 % opacity with the level, never faster than 0.6 s. |
| Choosing an area | G dashed stroke, M handles / label | Dashes march while dragging. |
| Choosing a window | M line + 22 % wash | 120 ms cross-fade between windows |
| Countdown | `rec` ring | The ring drains each second; at 0 the selection stroke cross-fades G → `rec` in 200 ms. |
| Recording | `rec` frame and dot | The island dot breathes (1.6 s); the frame is still. |
| Paused | `attn` dashed | No motion: stillness is the signal. |
| Snap | white shutter / M ring + glow | 320 / 450 ms, once |
| Card hung | M clasp | The card swings in on the spring; the clasp does not animate. |
| blurt working | I spinner arc, M dot | Quarter arc, 1.1 s per turn |
| Done | `ok` + ✓ | The check draws once (200 ms); the chick hops. The colour never pulses. |
| Needs you | `attn` | One pulse when it appears, then still. |
| Primary button | G | Brightness 1.04 on hover (120 ms). The gradient never animates or shifts. |

Rules: at most one brand-coloured thing moves at a time on a screen; the gradient itself never moves (no animated
gradient angles, no shimmer); glow only while listening or capturing; nothing in brand colour blinks for an error.

## 5. Gradient recipes

### 5.1 AppKit / Core Animation

Three tools, by surface:

| Surface | How | Why |
|---|---|---|
| Buttons, Snap, island fill buttons, live-text rule | `CAGradientLayer` (`gradient.linear`), no grain | Resizes for free; crisp at any scale. |
| Capture stroke, level bars | `CAGradientLayer` **masked** by a `CAShapeLayer` (the dashed rect / the bars path) | The gradient follows the shape; dash phase and bar heights animate on the mask. |
| Icon tile, empty-state art, onboarding hero, glow | **Pre-rendered PNG @1x / @2x** generated by `assets/color/build.py` (same SVG recipe as the icon, grain included); for a hero panel that resizes, a `FieldView` that draws the field with `CGContext.drawRadialGradient` plus the grain tile in `draw(_:)`, cached per size and appearance | Radial ellipses and grain are cheap to render once and crisp at the exact pixel size. Live Core Image blur or noise on layers is avoidable work. |

```swift
// Generated from tokens.json (sketch).
enum BrandGradient {
    static let green = NSColor(srgbRed: 0x66/255, green: 0xD9/255, blue: 0x7A/255, alpha: 1)
    static let mint  = BrandColor.fill                                   // #61DBBD, the seam
    static let blue  = NSColor(srgbRed: 0x4A/255, green: 0xAB/255, blue: 0xE2/255, alpha: 1)

    /// gradient.linear, corner to corner (CSS `to bottom right`). An unflipped layer has y up, so top-left is (0, 1).
    static func linear(_ l: CAGradientLayer = CAGradientLayer(), flipped: Bool = false) -> CAGradientLayer {
        l.colors = [green, mint, blue].map(\.cgColor)
        l.locations = [0, 0.45, 1]
        l.startPoint = CGPoint(x: 0, y: flipped ? 0 : 1)
        l.endPoint = CGPoint(x: 1, y: flipped ? 1 : 0)
        return l
    }

    /// gradient.vertical across a group box (the island level bars): green on top.
    static func vertical(flipped: Bool = false) -> CAGradientLayer {
        let l = linear()
        l.startPoint = CGPoint(x: 0.5, y: flipped ? 0 : 1)
        l.endPoint = CGPoint(x: 0.5, y: flipped ? 1 : 0)
        return l
    }
}

// The capture stroke: a dark under-stroke, then the gradient seen through a dashed mask.
let under = CAShapeLayer()
under.path = rectPath; under.fillColor = nil
under.strokeColor = BrandColor.on.withAlphaComponent(0.6).cgColor; under.lineWidth = 2
let dash = CAShapeLayer()
dash.path = rectPath; dash.fillColor = nil; dash.strokeColor = NSColor.black.cgColor
dash.lineWidth = 2; dash.lineDashPattern = [6, 4]
let stroke = BrandGradient.linear(); stroke.frame = bounds; stroke.mask = dash
// marching: animate dash.lineDashPhase 0 → 10 over 1 s, repeat; skip with reduceMotion

// Level bars: the existing bars path becomes the mask of a vertical gradient over the 18 pt box.
let level = BrandGradient.vertical(); level.frame = groupBox; level.mask = bars   // bars.strokeColor = black

// Primary button: a layer-backed NSButton subclass (bezelColor can't carry a gradient).
final class BrandButton: NSButton {
    private let fill = BrandGradient.linear()
    override func makeBackingLayer() -> CALayer { let l = CALayer(); l.addSublayer(fill); return l }
    override func layout() { super.layout(); fill.frame = bounds; fill.cornerRadius = 7 }
    // title: attributedTitle in BrandColor.on; highlight: a 1 pt white 35 % top inset layer;
    // isHighlighted → fill.opacity / a 6 % black overlay; !isEnabled → neutral fill, gradient hidden.
}
```

Grain on a resizable `FieldView`: a 256 px monochrome noise tile (generated, @2x) drawn with
`ctx.setBlendMode(.overlay)` at alpha 0.10 (light) / 0.08 (dark), tiled with `CGContext.draw(_:in:byTiling: true)`
in device pixels (scale the CTM by `1 / backingScaleFactor`) so it stays one grain per pixel on any display. Rebuild
when the bounds or the appearance change.

All colours are sRGB (`NSColor(srgbRed:…)`). The old `accent`, `amber` and `dictationTint` are calibrated RGB, so the
same numbers render a hair differently from the web.

## 8. Spacing, radius, elevation (as used today)

- **Spacing**: a 2 / 4 pt grid. Stack spacings are mostly 2, 4, 6, 8, 10 and 12. Hanging cards: 12 pt gap, 12 pt from
  screen edges, 18 pt below the island. Island rows: 18 pt side inset, selection inset 6 × 1. Controls 28 px high on
  mac web (`--ctl-h`), 32 win, 34 GNOME.
- **Radius**: 6 (rows, palette selection, small controls; web `--r-sm`), 7–9 (image cards, island row wash, buttons,
  note pill), 10 (panels, tips; web `--r` 10 mac / 8 win / 12 GNOME), 12 (voice cards, large cards), 14 (note bubble,
  island bottom corners). Pills and dots are height / 2. Handles 2.5. Gradient art tiles are ≈ 30 % of the side. The
  app icon is the macOS superellipse.
- **Elevation**: dark mode shows hierarchy with lighter surfaces, not shadows (`#1E1E1E → #2A2A2A → #323232`). Light
  mode has two shadows: `--shadow` (1 px + 10/28 soft) and `--shadow-pop` (0.5 px ring + 16/44). Hanging cards use a
  10–12 pt shadow radius; clasps 1.5. Capture chrome is glass (white 0.05–0.08 @ 72–82 %), not shadow. Screenshots get
  a 1 px inner stroke. The gradient adds no new elevation: a gradient button has the same 1 px shadow as any button.
