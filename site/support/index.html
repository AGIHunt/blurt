Blurt Support

Blurt on iPhone and iPad gives you a trackpad, shortcuts, live screen view and a microphone for your computer. It requires the Blurt companion app on a Mac, Windows or Linux computer.

Pair your device

  1. Download Blurt for your computer and open its Remote Control page.
  2. Choose Add Device, then scan the QR code in the iPhone or iPad app.
  3. Check that the confirmation code matches on both screens, then approve the request on the computer.

Troubleshoot

For first-time setup, keep the devices on the same network and allow Local Network access on your iPhone or iPad. For missing screen or input controls, check the permissions shown on the computer’s Remote Control page. If dictation uses the wrong microphone, check the Dictation settings in the mobile app.

Contact the team

Email contact@agihunt.cc for help or a private privacy request. For public feedback and feature requests, open a GitHub issue. Include your device, system version and what you were trying to do. Keep pairing codes, personal details and private logs out of public issues.

口喷鸡支持

你可以用 iPhone 或 iPad 当触控板、用快捷键、看电脑画面和听写。请先在 Mac、Windows 或 Linux 电脑上安装口喷鸡桌面端。

配对设备

  1. 下载电脑端口喷鸡，打开「远程控制」页面。
  2. 选择「添加设备」，用 iPhone 或 iPad 上的口喷鸡扫描二维码。
  3. 确认两台设备显示的验证码一致，然后在电脑上同意配对。

遇到问题

首次配对时，请让两台设备连接同一个网络，并允许 iPhone 或 iPad 访问本地网络。画面或远程输入不可用时，检查电脑端「远程控制」页面提示的权限。听写用了错误的麦克风时，可以在移动端的听写设置中切换。

联系我们

需要帮助或希望私下提出隐私请求，请发邮件至 contact@agihunt.cc。也可以在 GitHub 上公开反馈或建议功能。请附上设备、系统版本和遇到问题时的操作，勿在公开议题中提交配对码、个人信息或私密日志。
