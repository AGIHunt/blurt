# lens: idea — something to build, change or try

Use for: feature ideas, product directions, "wouldn't it be cool if…", things the user liked elsewhere and wants
to borrow ("这个网站的这里好"), design inspiration.

Fields:
- `summary` — the idea in 1–3 plain sentences, as the user meant it (sharpen, don't embellish).
- `why` — the motivation / problem / insight behind it.
- `inspired_by` — what triggered it on screen (site, product, screen) — also set `source.url` when readable.
- `next_steps` — list: the smallest concrete things to try / decide / prototype.
- `open_questions` — list, optional.
- `tags`.

Frames: the thing that inspired it (the section of the page the user pointed at), not just the whole page. When
they circled it with the pen, that frame — their ink included — is the one to use.
Group related ideas: when several items are facets of one idea, merge them. For idea-heavy sessions write the
session `digest`: themes, the strongest 3 ideas, how they connect, suggested next step.
When the ideas add up to one thing to build, the user may want a document instead of a board: `reference/docs.md`.
Export default: an ideas board (Markdown / Feishu table: 想法 / 为什么 / 灵感来源 / 下一步 / 截图).
